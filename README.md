# TANUVA Website

Editorial concept website for TANUVA, an Advanced Skincare Technology House.

> Quiet science. Made visible.

## Direction

The experience translates immersive luxury-skincare storytelling into TANUVA's own system: evidence-led copy, warm white and petal tones, restrained motion, generous editorial pacing, and a clear separation between the TANUVA logotype and rose emblem.

## Run locally

```bash
npm ci
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Core stack

- Next.js / React
- Vinext and Vite
- TypeScript
- Responsive custom CSS
- TANUVA brand fonts and supplied identity assets
